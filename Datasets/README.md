# Self-Collected Datasets
In this paper, we collect 6 mobile app traffic trace datasets, which include a single-app multi-flow dataset `SAMF`, a multi-app multi-flow dataset `MAMF`, four dynamic networking environment datasets: `SAMF-Drift, SAMF-Region, SAMF-Net, SAMF-Failure`.

To avoid the risk of sensitive traffic data leakage, we have only provided a demonstration sample in `./Traffic_Traces/SAMF/air.tv.douyu.android`. The complete self-collected datasets will be released after our paper is accepted.
